# Witch 문서 언어 정책

[한국어](documentation-policy.ko.md) · [English](documentation-policy.md)

Witch의 공개 문서는 영어판과 한국어판을 별도 파일로 관리합니다.

- 영어판은 `README.md`, `docs/methodology.md`처럼 기본 `.md` 경로를 사용합니다.
- 한국어판은 `README.ko.md`, `docs/methodology.ko.md`처럼 대응하는 `.ko.md` 경로를 사용합니다.
- 두 파일 상단에는 서로 이동할 수 있는 언어 링크를 둡니다.
- 사용자가 처음 접하는 문서는 핵심 사용법, 지원 범위, 검증 결과와 안전 경계를 양쪽 판에서 동등하게 제공합니다.
- 새로 추가하거나 의미를 바꾸는 규범적 요구사항, 안전 경계와 평가 해석은 두 파일을 함께 갱신합니다.
- 코드, 명령, API 이름, IR schema, metric 이름과 측정값은 번역 과정에서 바꾸지 않습니다.
- 자동 생성 문서는 생성기 자체가 영어 파일과 한국어 파일을 모두 출력해야 합니다.
- 두 언어가 충돌하면 구현과 검증 evidence를 다시 확인해 같은 의미로 고칩니다. 어느 한쪽을 임의로 우선해 사실을 바꾸지 않습니다.

`npm run docs:check`는 추적 중인 Markdown 문서의 언어판 쌍과 상호 이동 링크를 검사합니다. 이 검사는 번역 품질을 대신하지 않으므로 리뷰에서는 의미, 수치, 링크와 비지원 범위의 일치도 함께 확인해야 합니다.
