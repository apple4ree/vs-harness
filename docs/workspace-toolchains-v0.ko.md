# Witch Workspace Toolchains v0

[한국어](workspace-toolchains-v0.ko.md) · [English](workspace-toolchains-v0.md)

프로젝트 코드를 실행하지 않고 Python 환경과 uv·Poetry·Ruff·Cargo 도구를 발견하고, 사용자가 승인한 Task로 연결하는 규칙을 설명합니다.

> 이 한국어판은 현재 관리되는 핵심 범위 요약을 제공합니다. 전체 기술 세부 내용과 원본 표는 [영어판](workspace-toolchains-v0.md)에서 확인할 수 있습니다.
