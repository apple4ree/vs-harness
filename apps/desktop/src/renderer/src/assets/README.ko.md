# Witch 시각 자산

[한국어](README.ko.md) · [English](README.md)

이 폴더의 PNG 파일은 OpenAI 이미지 생성 도구로 Witch를 위해 만든 원본 자산입니다. 제3자 캐릭터 아트, 로고 또는 게임 자산은 포함하지 않습니다.

- `witch-astral-observatory.png`: 투명 배경의 companion 빈 상태 emblem
- `witch-constellation-atmosphere.png`: 투명 배경의 architecture canvas 가장자리 장식

제품의 의미나 탐색이 생성 이미지에 의존하지 않도록 이 시각 요소는 장식으로만 사용하고 `alt=""`와 `aria-hidden="true"`를 적용합니다.
