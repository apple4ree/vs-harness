> **English:** This directory documents Witch's original decorative images and their accessibility rules. It contains no third-party character, logo, or game assets.

The PNG files in this directory are original assets generated for Witch with
OpenAI's image generation tool. They do not include third-party character art,
logos, or game assets.

- `witch-astral-observatory.png`: transparent companion empty-state emblem.
- `witch-constellation-atmosphere.png`: transparent architecture-canvas edge
  ornament.

Keep these visuals decorative (`alt=""` and `aria-hidden="true"`) so product
meaning and navigation never depend on generated imagery.
